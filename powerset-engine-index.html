Powerset Engine

Define an NFA with several targets per input (and ε-moves), and get the equivalent DFA built by subset construction. Every step of the construction is shown, and you can run strings through both machines.

NFA definition

One per line: state symbol -> target target …. Use ε, eps or λ for an empty move. Lines starting with # are ignored. States and the alphabet are read from the lines.
